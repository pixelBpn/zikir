Kebijakan Privasi / Privacy Policy

Halaman ini memberikan informasi mengenai kebijakan kami terkait pengumpulan, penggunaan, dan pengungkapan data pribadi saat Anda menggunakan aplikasi Dzikir & Do'a (ID: pixelhandil.zikr).

Ringkasan Ringkas: Aplikasi Dzikir & Do'a berkomitmen penuh untuk menjaga privasi Anda. Kami tidak mengumpulkan data identitas pribadi, lokasi GPS, atau data sensitif pengguna.

1. Pengumpulan dan Penggunaan Data

Aplikasi ini dirancang untuk dapat digunakan secara offline dan tidak mewajibkan pengguna untuk melakukan pendaftaran akun. Oleh karena itu:

  • Informasi Pribadi: Kami tidak meminta, mengumpulkan, atau menyimpan nama, alamat email, nomor telepon, atau data pribadi lainnya.
  • Data Perangkat: Aplikasi tidak mengambil data identifikasi unik dari perangkat Anda untuk tujuan pelacakan individu.

2. Izin Perangkat (Permissions)

Untuk menjalankan fitur-fitur di dalam aplikasi secara optimal, aplikasi mungkin memerlukan izin tertentu pada perangkat Anda, seperti:

  • Akses Penyimpanan Internal / Storage: Hanya digunakan untuk menyimpan preferensi aplikasi atau data lokal (seperti setelan aplikasi, gambar nasihat,) di dalam perangkat Anda sendiri. Data ini tidak dikirim ke server luar.
  • Notifikasi: Digunakan untuk menampilkan pengingat waktu dzikir atau do'a (jika fitur pengingat diaktifkan oleh pengguna).
  • Lokasi: Digunakan untuk mencari posisi waktu sholat di fitur Jam sholat.

3. Layanan Pihak Ketiga

Aplikasi ini dapat menggunakan layanan pihak ketiga yang mungkin mengumpulkan informasi yang digunakan untuk mengidentifikasi Anda secara anonim (misalnya untuk analitik performa aplikasi).

Tautan ke kebijakan privasi penyedia layanan pihak ketiga yang digunakan oleh aplikasi:

  • Google Play Services

4. Keamanan Data

Kami sangat menghargai kepercayaan Anda dalam menggunakan aplikasi ini. Karena aplikasi tidak mengumpulkan data pribadi ke server eksternal, risiko kebocoran data pribadi Anda sangatlah minim. Semua preferensi penggunaan disimpan secara lokal di perangkat Anda.

5. Kebijakan Privasi Anak-Anak

Aplikasi ini aman digunakan oleh semua umur, termasuk anak-anak. Kami tidak secara sadar mengumpulkan informasi teridentifikasi pribadi dari anak-anak di bawah usia 13 tahun.

6. Perubahan Kebijakan Privasi Ini

Kami dapat memperbarui Kebijakan Privasi kami dari waktu ke waktu. Oleh karena itu, Anda disarankan untuk meninjau halaman ini secara berkala untuk mengetahui perubahan apa pun. Perubahan berlaku efektif segera setelah diunggah ke halaman ini.

7. Hubungi Kami

Jika Anda memiliki pertanyaan atau saran tentang Kebijakan Privasi kami, jangan ragu untuk menghubungi kami melalui tautan atau halaman pengembang resmi kami.
